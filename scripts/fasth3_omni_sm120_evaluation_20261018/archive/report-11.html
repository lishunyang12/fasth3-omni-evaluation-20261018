# C4 source attribution

This run profiles the same native128 C4 code with `CUTE_DSL_LINEINFO=1`.
It supplies source attribution missing from the normal optimized build's
source report. The harness, raw report and KDA helper extraction are retained
locally. No performance claims are derived from this debug-metadata run.
The main six-dimension analysis is in `../native128-c4-promoted/REPORT.md`.
