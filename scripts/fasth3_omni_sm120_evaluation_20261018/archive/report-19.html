C5 native SM120 block128: frozen evaluation

Decision: retain the native128 opt-in with C5. The 16K scheduling cliff is
fixed on the measured prefix workloads, while long-sequence performance is
preserved within small measured tradeoffs. This is not a universal FI win.

Implementation
  - Four initial query tiles across heads, then groups of128 at every length.
  - Nq/H compile constants, already covered by the device/shape/stride cache key.
  - Compaction optionally removes size=0 KV blocks; from-mask API enables it.
  - Nonempty tiles remain128x128; BF16 inputs/P and FP32 accumulation unchanged.
  - compact_mask_sm120(mask) and direct compact-index callers remain compatible.
  - No CPU metadata reads, data-dependent dispatch, quantization or new model weights.

Independent validation
  correctness: 45 passed, 0 failures.
  boundary: 9 passed, 0 failures.
  holdout: 25 passed, 0 failures.
  regression: 23 passed, 0 failures.
  27 GPU pytest cases passed, including graph mutation, concurrent graphs,
  cross-device DLPack binding, fullgraph compile, poisoned padding and outputs.
  Output gates: atol=.01, rtol=.01, relative-L2<=.005; lnLSE .002/.0002.
  TF32 disabled. Small references use FP64; long cases cover boundary rows
  in EVERY Q block plus seeded random rows. Empty rows exactly zero/-inf.
  FI is excluded only for the 16-byte-offset input: its pinned wrapper assumes128-byte alignment.
  Fresh performance and boundary cases additionally compare EVERY output
  against frozen C4.1; reference checks remain independent of both kernels.
  Maximum max_abs across the 45-case suite: 0.0141015053
  Maximum rmse across the 45-case suite: 0.000795068394
  Maximum relative_l2 across the 45-case suite: 0.00225098198
  Maximum lse_max_abs across the 45-case suite: 6.90810643e-05
  The largest absolute error occurs with amplified logits; the combined
  absolute/relative gate and relative-L2 gate both pass without tolerance changes.
  Maximum full-output BF16 difference versus C4.1: 0

Performance protocol
  GPU2 for all final timing/repeats; 21 randomized paired rounds per case.
  Hot: 3 warm replays then10 timed replays. Cold:256MiB cache flush before
  each timed replay (flush excluded); GPU L2=96MiB. Eager host-inclusive
  samples and before/after GPU telemetry are retained in each JSON.
  Kernel uses precomputed metadata/preallocated output; full includes
  allocation and fused mask compaction. FI gets a fused128-to64 adapter.
  Raw samples and paired bootstrap95% intervals (2000 resamples) are stored;
  these intervals describe within-process variability, not cross-machine confidence.
  C4.1 frozen before tuning. C5 frozen before fresh holdout. No holdout retuning.
  Holdout seed67057; original regression seed41113. Tuning seed58013.
  FI commit f75bed5da7112103b75f82a4d4b5faf4be335154.
  Speed ratios >1 mean C5 is faster. Do not infer model latency from these kernels.
