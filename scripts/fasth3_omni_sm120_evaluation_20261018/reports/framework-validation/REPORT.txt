Native128 VSA integration into vLLM-Omni — 2026-10-18

Recommended local configuration for this SM120 FastH3 checkpoint:
  FASTVIDEO_VSA_SM120=1
  FASTVIDEO_VSA_SM120_SPLITS=1
  --diffusion-attention-backend FASTVIDEO_VSA

Use the final local C6b source in fastvideo-sm120-tile128. Its default
num_splits=1 retains the frozen C5 unsplit schedule and arithmetic; C6b adds
explicit split-KV options, not a universally faster replacement path.
The checkpoint explicitly declares num_attention_heads=56 and D=128.
Pure Ulysses4 therefore leaves14 heads per rank (without additional TP).
hidden_size=5376 must not be divided by D to infer the attention head count:
the attention projection inner dimension is independently56*128.

Selection evidence:
- validation-v3/REPORT.txt: synthetic H14 prefix cases at8192/16384/32768
  tokens have FI/C5 kernel speed ratios1.2665/1.2177/1.1526.
- profile/native128-c5-candidate/REPORT.md: at32768/H56, elapsed-cycle
  BF16 dense SoL85.59%, SM busy99.50%, no measured register spills.
- validation-v4/REPORT.txt: C6b default output/LSE bitwise equals frozenC5
  on23 regression cases. Split8 wins selected H1 prefix holdouts, but loses
  badly on ultra-sparse/single/empty patterns. Do not enable it by head count
  alone. FI can still win partly valid128-block and ultra-sparse cases.
- These are kernel measurements on synthetic inputs, not model latency or
  output-quality measurements. No claim of a universally best VSA is made.

Integration changes:
- Production vllm_omni::fastvideo_block_sparse_attn_bshd dispatches the native
  provider for tile128 on SM120 when explicitly enabled. Device capability
  uses current_omni_platform. A native failure is propagated.
- Preserve the logical128 mask, valid sizes, independent video-region
  budgets, and compression gate. Remove transport-only tiles before launch
  and restore their outputs as exact zero rows.
- FASTVIDEO_VSA_SM120_SPLITS is read at invocation; configure it before
  warming/capturing CUDA graphs. The kernel validates1/2/4/8/16.
- CPU tests cover unchanged logical masks, stripping poisoned transport
  blocks, splits1/8 forwarding, and propagated errors. Existing test stubs
  now use setattr for dynamically attached module attributes, satisfying
  the repository's mypy checks without suppressions.
