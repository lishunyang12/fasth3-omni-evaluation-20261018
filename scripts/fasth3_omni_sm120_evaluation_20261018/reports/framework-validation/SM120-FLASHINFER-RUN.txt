SM120 FlashInfer deployment and regression commands (2026-10-18)

Selected provider: unmodified upstream FlashInfer BF16 SM120 block64 kernel.
Model routing: logical128, (4,4,8) video tiles, 90% sparsity, independent
reference-region budgets, PDD8 forwards, shifts12/3, guidance1.
No FASTVIDEO_VSA_SM120 or FASTVIDEO_VSA_SM120_SPLITS setting is required.
The serving/offline backend name remains FASTVIDEO_VSA, not FLASHINFER_ATTN;
the latter selects a different attention implementation and is not this VSA adapter.

This machine's runtime:
  Python3.12.13, torch2.13.0+cu130, vllm0.30.0 overlay, Triton3.7.1,
  CUTLASS DSL4.6.2, CUDA Python13.3.1, driver580.95.05.
  FlashInfer revision f75bed5da7112103b75f82a4d4b5faf4be335154.
  run_flashinfer.py uses upstream FastVideo helpers and excludes the custom
  fastvideo-sm120-tile128 directory from PYTHONPATH.
  Installed Omni distribution metadata says0.28.0; checked-out code expects
  vllm0.30.0. Tested offline generation works; other serving APIs are not
  certified by these tests.
  FFmpeg/FFprobe must be on PATH. Full model weights are already hash-verified
  and cached locally; the commands below use offline Hugging Face access.
