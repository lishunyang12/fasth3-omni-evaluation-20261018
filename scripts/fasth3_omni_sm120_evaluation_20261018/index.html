04 / 失败实验和结论边界

实验观察可以得出的结论
无 HSDP，全组件常驻构建文本编码器期间 OOM；GPU 71.12 GiB 总量，剩余 12.50 MiB，申请 32 MiB 失败。没有无 HSDP 常驻的完整请求计时。
无 HSDP，整模块 CPU offload43.445352 / 43.345245 / 43.386210 s；中位数 43.386210 s。比此前常驻 HSDP8 41.057672 s 慢 5.67%；驻留策略同时改变，不能当作纯 HSDP 因果差值。
HSDP8，同样 CPU offload完成初始化，首请求在 DiT 参数移动 CPU/CUDA storage 时失败。此运行时 offloader 路径失败；没有匹配 offload 的 on/off latency 或 latent 对照。
进度日志外推“无 HSDP 常驻 ~35.4 s”从四舍五入的步耗时估算；实际常驻配置 OOM。仅为历史阶段估计，不计入实测加速。
HSDP4/USP8、root-only 保留权重有权重与通信量推算。仍未实测；早期 HSDP4/USP4 数据不能替代。

06 / 已评测路线：保留正负结果

当前选择 FI。早期 native128 在完整请求中仅快约 0.3%；局部 GEMM、attention 或 VAE kernel 收益不能自动折算为端到端收益。以下是历史记录的索引性摘要，完整条件与数字见各阶段原文。

路线当前判断
native128 split / CTA 调序 / ragged PV；early softmax / V copy；准备 CUDA Graph没有建立稳定完整请求收益，部分增加 spill 或明显变慢。
fine→O 分块、V 双缓冲、12 次通信合为 4 次、额外优先级与 gate stream部分退出默认路径；部分字节一致但受限计算链更慢；未作为当前加速。
CuTe FC1 / NN 布局 / tiles，O 八块分片局部收益未兑现为完整请求，或未通过严格一致性。
普通 VAE B2/B4/B7、B4/B3；修复后 B4/B3、全局 B8/B16部分 FP32 输出不一致；修复后部分通过资格但性能回退。
MLP→下一层 QKV/RDMA、fine prefix-first / Q-hoist、部分 FC2/w1 布局只有局部证据；PDL、forward V 分块消费旧记录尚未实现。
Sage/CAKE、DiT/VAE FP8 或 MXFP8、E4M3 wire、TAEH3、旧四步/选块、近似跨步缓存改变精度或模型合同。历史约 15 秒和旧 22 秒结果不属于当前 FI / Omni PDD8 / USP8 的可比加速。
早期实际 QKV 逐元素门限与 native/FI 对照曾出现失败或数值差异；合成用例通过不能覆盖这些失败。本页没有将 native 与 FI 声称为逐位等价。当前 13,048 对资格结果只比较同一 FI provider 下 HSDP2 与 HSDP8。

后续原定优先级：VSA 布局融合 → SM120 VAE 精确算子 → VAE 配对/B2 → 通信路径与 QK/V、gate、O 流水。各项仍需独立资格和正常完整请求 A/B。
