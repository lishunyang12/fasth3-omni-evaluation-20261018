为什么不能把这里的比值直接当作 GPU 性能差距？

设备之间的权重精度、attention、参考编码器、offload 和计时边界不同。DGX Spark / RTX 5090 使用 NVFP4；RTX 3090 为 FP8 权重、BF16 计算；M5 Max 为 INT6 且仅单次测量；8× GB200 数据来自发布文章。PRO 5000 使用 vLLM-Omni + CAKE，单卡与 4 卡均关闭 CPU offload，权重常驻 GPU。图表比较的是这些具体部署。

04 / REPRODUCIBILITY

每一个数字，都有出处。

原文矩阵的复测口径

  • 原文的五组参考文件与提示词，保留顺序；图片短边 2048，按 32 对齐，Lanczos 缩放。
  • 480p = 832 × 480；768p = 1344 × 768；8 步，124 帧，24 fps，双声道音频。
  • 每种输入、分辨率、解码器、卡数先预热一次，再测 seed 0 / 1 / 2。原文只说明三种子均值，未公布完整种子列表。
  • 计时从本机 HTTP 请求开始，到完整 MP4 接收结束；不包括服务启动和模型加载。
  • 36L 为 NVFP4 Quality 解码器，8L 为 NVFP4 Fast 解码器；36L 不是原版 BF16 解码器。
