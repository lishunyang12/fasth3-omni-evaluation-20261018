测试条件与结果边界
生成配置
1344 × 768，124 帧，24 fps，8 次前向；单请求串行；原生生成音频。
执行方式
Eager；无 CPU offload；USP 4、文本编码器 TP 4、VAE patch parallel 4；启用阶段计时。
计时范围
客户端请求至完整 MP4 返回，不含模型加载和预热。端到端与阶段耗时分别取三次请求的中位数。
一致性检查
正式测试每组的三次输出经完整解码验证，视频像素和音频分别一致。跨配置的画面相似度不作为主观质量评分。
覆盖范围
本页为 BF16 与 NVFP4 实测；未将 FP8、单卡消费级 GPU 或 Sage 整段视频性能列为已验证结果。
