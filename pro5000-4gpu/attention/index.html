FastH3: CAKE Sage
Experimental Results

These samples use the original BF16 model weights and video decoder with FlashInfer CAKE Sage attention: INT8 Q/K and FP8 V. We report the measured latency and generated outputs. A kernel baseline with the same attention precision has not yet been evaluated.

Comparison scope. These results do not establish a CAKE kernel speedup. Changing both the implementation and attention precision prevents attribution to the kernel alone. View the BF16 cuDNN and FastVideo comparison →

Implementation and missing BF16 experiment
The tested configuration explicitly invokes the SM120 CAKE Sage CUDA kernel. Q/K INT8 and V FP8 quantization use vLLM-Omni Triton adapters. An isolated evaluation launcher replaces H3 fine-attention while retaining logical tile128 routing and learned compression. The tested CAKE BF16 VSA implementation supports SM100/SM103; a CAKE BF16 VSA video result on SM120 is not available. The existing FlashInfer SM120 BF16 entry point uses CuTe DSL. Model-weight precision and attention precision are recorded separately.
