3 / METHOD AND PROVENANCE

Controlled inputs and timing scope

Inputs were captured at step/layer 0/0, 3/49, and 7/49 from the original BF16 FastH3 checkpoint. The original attention replay was verified against each stored output before extracting fine-attention operands. Logical tile128 selection is lowered to tile64 metadata while preserving selected valid tokens, variable block counts, and partial key/value blocks. Sparse routing and learned compression are outside the measured region.

Each implementation receives five compilation/warmup calls, followed by five graph warmups and 30 timed graph replays. Provider order rotates between repetitions. Both implementations retain native behavior, including cuDNN LSE writes. Small masked-attention checks cover variable counts and partial/padded blocks before measurements. Raw samples and numerical diagnostics are available below.

The cuDNN blk64 BSA kernel is from frontend 1.31.0. Its original quantizer failed to compile on SM120 because it emitted an unsupported FP32 redux instruction. The benchmark uses NVIDIA’s official upstream SM120 quantizer fix; the blk64 BSA source at that revision is byte-identical to 1.31.0. CAKE uses the explicit backend="cake" SM120 entry point and the vLLM-Omni Triton Q/K/V quantizers.
