v1.34 updates slide 11 with a full quantization comparison inside vLLM-Omni. Online and QAD both use native FP4 sparse attention and NVFP4 linear layers in the DiT, language encoder and video decoder. QAD retains checkpoint scales. Online is independently quantized from original weights, without QAD weights, QAD scale tables or calibration data. The fourth clip uses the same QAD weights with CAKE Sage attention.

The videos include request times and full-resolution LPIPS / SSIM. Single-request CPU-offload timings are not steady-state benchmarks. A single scene does not establish general quality; motion differences affect frame similarity. Earlier v1.30–v1.32 QAD videos used an incorrect activation-scale override and a narrower quantization scope; this release supersedes that comparison.

The 21-slide layout and existing communication / CUDA Graph analysis are retained. Four videos are embedded side by side in PowerPoint; the PDF uses still frames. Browser playback and shared seek were checked. The template audit retains the requested media-playback timing exception, with no other errors or warnings.
