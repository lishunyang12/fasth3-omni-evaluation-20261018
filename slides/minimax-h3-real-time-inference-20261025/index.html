Slide 17 explains that CUDA Graph is possible before head banding, while repeated per-band submissions strengthen its benefit. The retained compute-only four-arm experiment shows 0.39% improvement for seven heads together and 2.30% for 1/2/3/1 bands. Banding still adds compute cost; end-to-end improvement depends on communication overlap. Fixed shapes, stable buffers and repeated calls suit graph replay.

The graph timeline is conceptual, with enqueue points marked before GPU execution. GPU work can begin before the CPU launch API returns. RDMA, readiness events and full W_O stay outside this prototype capture. Selected 2/3/2 is not a measured full-model result. Textual arrows were replaced by words; diagram connectors remain.
