v1.23 closes the communication section: FI RDMA is 2.33–2.47× faster than the controlled local NCCL implementation across three sequence lengths. The topology separates the shared 128 GB/s NIC PCIe interface from each GPU’s 400G network port (50 GB/s per direction). Installed xGMI capacity is unverified; PCIe versus xGMI saturation is not isolated. These are communication microbenchmarks, not E2E speedups.
