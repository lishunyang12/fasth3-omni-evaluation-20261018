Measurement context

The ratios divide the retained BF16 request time by each variant’s request time. One request per variant includes CPU offload, generation and MP4 encoding, and excludes model loading. The variants ran on different GPUs in the same machine; these are descriptive cross-run ratios, not controlled production speedups.
