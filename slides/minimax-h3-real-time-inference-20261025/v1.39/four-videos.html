Comparison: same scene, prompt, seed 1234, resolution and eight evaluations in vLLM-Omni. The fourth column uses QAD + Native FP4 with unified prefix / video computation and device-aware SM scheduling. This experimental variant changes prefix precision relative to baseline QAD.

*Timing: one request per variant with layerwise CPU offload, generation and MP4 encoding; model loading is excluded. BF16 is retained from GPU 0, Online and baseline QAD from GPU 3, and QAD + Native FP4 runs on GPU 1 of the same machine. First-use work varies; these are not controlled production-speed measurements.

Metrics: LPIPS AlexNet v0.1 and RGB Gaussian SSIM average all 124 full-resolution decoded frames, matched by index. Lower LPIPS and higher SSIM mean closer to this BF16 reference. A single scene does not establish general quality, temporal consistency or audio quality.
